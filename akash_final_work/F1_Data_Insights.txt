1. The biggest discovery: 2023 is massively anomalous

| Year |    Rows | PitNextLap = 1 |
| ---- | ------: | -------------: |
| 2022 |  82,989 |     **26.65%** |
| 2023 | 136,147 |      **0.96%** |
| 2024 | 127,110 |     **29.53%** |
| 2025 |  92,894 |     **28.44%** |


2023 represents 31% of your entire training data, but its positive rate is only 0.96%.

That is not a small distribution shift.

It is enormous.

A model can easily learn:

Year = 2023 → almost never pit

and obtain deceptively strong validation performance if your validation split preserves this same anomaly.

This is one of the first things I would investigate before doing serious modeling.


#######################################



2. Target imbalance

Overall:

PitNextLap = 0: 80.10%
PitNextLap = 1: 19.90%
Positive examples: 87,381
Negative examples: 351,759

So this is roughly a 4:1 imbalance.

This is why ROC-AUC is much more useful than accuracy for this competition.

A classifier predicting 0 almost everywhere could have ~80% accuracy while being practically useless.

4. Stint is exceptionally important

The target rate by stint is:

Stint	PitNextLap rate
1	5.98%
2	39.11%
3	29.31%

The jump from Stint 1 → Stint 2 is huge.

This makes sense conceptually:

Stint 1 = starting tyre
Stint 2 = after first pit
Stint 3 = after another strategic event
etc.

But there is an important warning:

Stint is not independent of LapNumber, TyreLife and RaceProgress.

The correlation structure shows:

LapNumber ↔ RaceProgress: ρ ≈ 0.98
LapNumber ↔ Stint: ρ ≈ 0.74
LapNumber ↔ TyreLife: ρ ≈ 0.70

So Stint is powerful partly because it represents where the driver is in the overall race strategy.

7. Compound is useful — but don't interpret it independently


| Compound     | PitNextLap |
| ------------ | ---------: |
| HARD         | **32.75%** |
| SOFT         |     19.35% |
| INTERMEDIATE |     15.23% |
| MEDIUM       |     10.11% |
| WET          |      2.51% |


At first glance this looks counterintuitive.

You might expect Soft tyres to lead to more pit stops because they degrade faster.

But the data says Hard has the highest raw pit probability.

This is exactly why you shouldn't make conclusions from one categorical feature in isolation.

Hard is strongly associated with:

certain years
certain stints
specific race strategies
later race phases

For example, Hard + Stint 2 has about 38.4% positive rate.

Medium + Stint 2 is even higher at about 44.8%.

So the important feature isn't simply:

"Which compound?"

It is closer to:

"Which compound + how old + which stint + where in the race?"

10. Cumulative_Degradation is NOT behaving like a simple degradation variable

This is another very important discovery.

Its Spearman correlation with target is:

−0.154

That might initially make you think:

"More degradation → lower probability of pit."

But that's misleading.

Its relationship is non-linear.

The target rate across degradation deciles is approximately:

Very negative     ~32.9%
       ↓
       ~23.7%
       ↓
       ~25.2%
       ↓
       ~29.3%
       ↓
       ~20.3%
       ↓
       ~11.2%
       ↓
       ~14.6%
       ↓
       ~11.6%
       ↓
       ~16.0%
       ↓
Very positive     ~14.2%


So a linear model would miss a lot of this structure.

Interesting tail behavior

Rows with:

Cumulative_Degradation < -200

have approximately 58.6% positive rate.

That's extremely unusual.

This feature therefore deserves:

nonlinear treatment
tree models
interaction analysis
potentially clipping/winsorization experiments

rather than simply assuming it represents "higher degradation = more likely pit."

##################################

12. RaceProgress and LapNumber are almost the same information


Spearman:

ρ ≈ 0.98

That's extremely high.

This means you should be careful when interpreting feature importance.

If a LightGBM/CatBoost model says:

RaceProgress importance = high
LapNumber importance = low

that doesn't mean LapNumber is useless.

The model may simply have found that one of the two can represent the same information.

Similarly:

LapNumber ↔ Stint ≈ 0.74
LapNumber ↔ TyreLife ≈ 0.70

This is a highly structured dataset, not an independent-feature tabular dataset.

Correlation with target:

Pearson ≈ −0.034

Spearman ≈ −0.055

That's barely above random.

This is important because you might naturally assume:

"A slower lap means the tyre is dying, therefore the driver will pit."

The dataset does not support that as a strong direct relationship.

20. There is a very interesting sequence relationship

I also checked whether:

PitNextLap

is simply equal to the PitStop value on the next lap for the same driver/race.

It isn't exact.

Even when restricting to rows where the next lap is actually consecutive, the relationship is only about 81% accurate.

So we cannot simply reconstruct the target as "next row PitStop."

That's important.

It means the target contains additional structure/noise rather than being a trivial deterministic transformation of the available rows.

Why not SMOTE to handle imabalnce dataset. (Are we using SMOTE?)
No.

And that's deliberate.

For this particular problem, I would not make SMOTE the default solution.

Why?

Because our data is not ordinary independent tabular data.

We have:

Year
Race
Driver
LapNumber
Stint
TyreLife
RaceProgress

and multiple rows belong to the same race/driver sequence.

If we generate synthetic observations with SMOTE, we could create artificial combinations such as:

Driver = D109
Race = Monaco
Stint = 4
LapNumber = 12
TyreLife = 28

that may not represent a physically/strategically realistic race state.

It can also complicate group-aware validation.

So instead, we're primarily handling imbalance through "class weighting" + an appropriate evaluation metric.

exmple =>> class_weight='balanced'
